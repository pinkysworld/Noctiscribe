# NoctiScribe

Official public website for NoctiScribe, a privacy-first sleep speech journal for iPhone and Apple Watch.

The site is static and dependency-free. It provides the product overview, privacy policy, terms of use, and support contact required for the App Store listing.

## Live pages

- Home: https://pinkysworld.github.io/Noctiscribe/
- Privacy: https://pinkysworld.github.io/Noctiscribe/privacy.html
- Terms: https://pinkysworld.github.io/Noctiscribe/terms.html
- Support: https://pinkysworld.github.io/Noctiscribe/support.html

## Publishing

GitHub Pages is configured to deploy from the main branch root.
